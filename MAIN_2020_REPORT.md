## Stage 2: Parsed Sparse Chunks (Combined)

Generated by `lib/unify_parsed_candump.py` into `../data/parsed/sparse` as `*_combined_chunk_*.hdf5`. Only **selected** candump files from `main_2020.py:unify()` are combined with reference data, so this set is smaller than the full non-combined set.

| Input candump                   | Combined size |
| ------------------------------- | ------------: |
| `candump-2020-01-29_115602.log` |       1.86 GB |
| `candump-2020-01-30_054738.log` |       5.98 GB |
| `candump-2020-01-30_172000.log` |       4.79 GB |
| `candump-2020-02-01_064223.log` |       3.45 GB |
| `candump-2020-02-01_064222.log` |       3.23 GB |
| **Total**                       |  **19.31 GB** |

### Why combined is smaller than non-combined

- `main_2020.py:unify()` only targets a subset of the parsed logs (selected races), so many parsed chunks are never combined.
- The combine step only adds the **time-cropped** reference data that overlaps each chunk, so it does not dramatically expand file size.
